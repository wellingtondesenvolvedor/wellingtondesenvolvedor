Política de Privacidade

Última atualização: 15 de junho de 2026

Esta Política de Privacidade descreve como o aplicativo Pet Cuidados coleta, usa, armazena e protege dados dos usuários.

1. Informações Coletadas

O Pet Cuidados pode coletar e armazenar:

  • e-mail usado para criação e acesso à conta;
  • dados cadastrados pelo usuário sobre pets, como nome, espécie, raça, peso e foto;
  • dados cadastrados sobre cuidados, como tipo, título, descrição, orientações, datas, horários e configuração de lembretes;
  • identificador de usuário gerado pelo Firebase Authentication;
  • imagens selecionadas pelo usuário para foto dos pets.

O app não coleta localização, contatos, SMS, microfone, dados financeiros ou dados de saúde humana.

2. Como os Dados São Usados

Os dados são usados para:

  • autenticar o usuário;
  • salvar e sincronizar pets e cuidados;
  • exibir informações cadastradas no app;
  • enviar lembretes locais de cuidados;
  • permitir recuperação de senha por e-mail;
  • armazenar fotos dos pets quando o usuário escolhe uma imagem.

3. Serviços de Terceiros

O app usa serviços Firebase, fornecidos pelo Google:

  • Firebase Authentication, para login, cadastro e recuperação de senha;
  • Cloud Firestore, para armazenar dados de pets e cuidados;
  • Firebase Storage, para armazenar fotos dos pets.

As práticas de privacidade do Google/Firebase podem ser consultadas em:
https://firebase.google.com/support/privacy

4. Compartilhamento de Dados

O Pet Cuidados não vende dados pessoais.

Os dados podem ser processados por provedores necessários para o funcionamento do app, como Firebase/Google. Também podem ser divulgados quando exigido por lei ou ordem de autoridade competente.

5. Segurança

O app usa os mecanismos de segurança do Firebase para autenticação, armazenamento e tráfego de dados. As regras do Firebase Storage restringem acesso aos arquivos do usuário autenticado.

As senhas não são armazenadas no app nem no Firestore. A autenticação por senha é gerenciada pelo Firebase Authentication.

6. Retenção e Exclusão

Os dados permanecem armazenados enquanto a conta existir ou enquanto forem necessários para oferecer as funcionalidades do app.

Para solicitar exclusão de conta e dados associados, o usuário deve entrar em contato pelo canal indicado nesta política. Ao excluir uma conta, os dados associados ao usuário devem ser removidos, salvo quando houver obrigação legal de retenção.

7. Permissões do Dispositivo

O app pode solicitar:

  • acesso à galeria/fotos, para selecionar foto do pet;
  • permissão de notificações, para enviar lembretes locais;
  • permissão de alarmes exatos no Android, quando disponível, para melhorar a precisão dos lembretes.

As permissões são usadas apenas para as funcionalidades informadas.

8. Crianças

O app não é direcionado especificamente a crianças. Caso um responsável identifique uso indevido de dados, deve entrar em contato para solicitar remoção.

9. Alterações Nesta Política

Esta política pode ser atualizada para refletir mudanças no app, em requisitos legais ou em serviços utilizados. A data de atualização será alterada quando houver mudanças relevantes.
