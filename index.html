Classificação de Tumores de Mama com Regressão Logística

Python · Scikit-learn · Machine Learning

Projeto acadêmico de Machine Learning aplicado à saúde, desenvolvido para classificar tumores de mama como benignos ou malignos a partir do dataset Breast Cancer Wisconsin Diagnostic.

Problema Construir um modelo interpretável para apoiar a classificação binária de tumores mamários com base em características extraídas de imagens digitalizadas.
Solução Regressão Logística em Python, com exploração dos dados, pré-processamento, divisão treino/teste e avaliação por métricas de classificação.
Impacto Modelo com 96% de acurácia geral, 98% de precisão e 93% de recall para a classe maligna.
  • Dataset com 357 casos benignos e 212 malignos.
  • Uso de 30 características dos núcleos celulares, incluindo raio, textura, perímetro, área, concavidade, simetria e dimensão fractal.
  • Pré-processamento com mapeamento da variável alvo, exclusão de colunas identificadoras e imputação por média.
  • Avaliação com matriz de confusão, acurácia, precisão, recall e F1-score.
  • F1-score de 95% para a classe maligna e 97% para a classe benigna.

Stack: Python, Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib, Regressão Logística, Machine Learning e Análise Exploratória de Dados.
